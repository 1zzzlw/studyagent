# StudyAgent 学习文档模板

这份模板用于新增模块或重新组织现有模块。根据主题裁剪内容，不要为了套模板制造空章节。

## 一、模块 README 模板

```markdown
# 模块编号：模块名称

## 模块定位

- 前置模块：
- 后续模块：
- 本模块解决的问题：
- 本模块不包含的内容：

## 学习目标

学完后，你应该能够：

1. ……
2. ……
3. ……

## 版本与资料依据

- 项目依赖版本：
- 主要官方资料：
- 是否结合参考项目：否 / 是（只读路径与范围）

## 章节目录

| 章节 | 内容 | Notebook 练习结果 |
| --- | --- | --- |
| 01 | …… | 能观察到…… |
| 02 | …… | 能独立完成…… |

## Notebook 学习方法

1. 先读一章文档，不提前复制完整实现。
2. 按“单元格练习”逐步输入代码。
3. 每一步运行后记录输出和疑问。
4. 完成错误实验，再修复并复跑。
5. 在 Markdown 单元格中用自己的话总结。

默认在学习者已有或自行维护的 `.ipynb` 中练习，不建议另建 `.py` 测试文件。

## 模块完成标准

- [ ] 能解释……
- [ ] 能在 Notebook 中独立实现……
- [ ] 能通过输出或查询验证……
- [ ] 遇到……错误时知道先检查什么
```

## 三、根目录 README 更新检查表

新增或调整模块后逐项检查：

- [ ] 模块目录名、标题和链接一致
- [ ] 现有模块与计划模块被清楚区分
- [ ] 插入模块后，后续编号没有冲突
- [ ] 当前学习目标与模块状态一致
- [ ] 25 天或其他每日计划中的模块编号仍然正确
- [ ] 没有把“准备学习”描述成“已经实现”
- [ ] 没有误改与本次模块无关的路线内容

## 四、代码量控制检查表

- [ ] 每个代码片段只讲一个概念
- [ ] 详细代码按 Notebook Cell 拆分，学习者需要亲手输入和运行
- [ ] 未创建不必要的 `.py`、测试文件或完整示例项目
- [ ] 未覆盖已有 `.ipynb`
- [ ] 默认没有建议创建 `.py`、`tests/` 或 `manual_tests/`
- [ ] Notebook 路径代码没有使用 `__file__`
- [ ] 若用户明确要求代码，只实现了指定范围
