# 第 5 章：读取与向量查询

## 本章目标

区分 get 与 query，理解 query_texts、query_embeddings、n_results、include 和返回值形状。

## 1. get：按条件读取，不做相似度排序

~~~python
result = collection.get(ids=["doc-1", "doc-2"])
~~~

分页读取：

~~~python
result = collection.get(limit=100, offset=0)
~~~

get 适合：

- 已知 ID；
- 按 Metadata 或文档内容筛选；
- 分页遍历记录；
- 检查数据是否正确写入。

## 2. query：向量近邻搜索

使用文本查询：

~~~python
result = collection.query(
    query_texts=["如何学习 Chroma？"],
    n_results=5,
)
~~~

这要求 Collection 绑定可用的 Embedding Function。

直接提供查询向量：

~~~python
result = collection.query(
    query_embeddings=[[0.1, 0.2, 0.3]],
    n_results=5,
)
~~~

查询向量维度必须与集合中的向量维度一致。一次可以传入多个 query，query 是批量 API。

## 3. peek 与 count

~~~python
collection.peek()
collection.count()
~~~

peek 用于快速观察少量记录；count 只返回记录数量。它们都不是向量相似度查询。

## 4. include

~~~python
result = collection.query(
    query_embeddings=[[0.1, 0.2, 0.3]],
    n_results=3,
    include=["documents", "metadatas", "distances", "embeddings"],
)
~~~

ids 始终返回，其余字段由 include 控制。没有出现在 include 中的字段可能为 None，读取前要检查。

## 5. 返回结构差异

get 返回扁平列表：

~~~text
ids:        [id1, id2]
documents:  [doc1, doc2]
metadatas:  [meta1, meta2]
~~~

query 按每个输入查询分组：

~~~text
ids:        [[id1, id2], [id3, id4]]
documents:  [[doc1, doc2], [doc3, doc4]]
distances:  [[d1, d2], [d3, d4]]
~~~

把 query 结果误当成 get 的扁平结构，是常见下标错误来源。
