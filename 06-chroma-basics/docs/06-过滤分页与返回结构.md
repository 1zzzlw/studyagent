# 第 6 章：过滤、分页与返回结构

## 本章目标

掌握 Metadata 过滤、文档内容过滤、逻辑组合、ID 限制和分页。

## 1. Metadata 等值过滤

~~~python
collection.get(where={"category": "technology"})
~~~

简写等价于：

~~~python
collection.get(where={"category": {"$eq": "technology"}})
~~~

## 2. 比较操作符

| 操作符 | 含义 |
| --- | --- |
| $eq | 等于 |
| $ne | 不等于 |
| $gt | 大于 |
| $gte | 大于等于 |
| $lt | 小于 |
| $lte | 小于等于 |
| $in | 位于给定列表 |
| $nin | 不在给定列表 |

~~~python
collection.get(where={"year": {"$gte": 2025}})
collection.get(where={"category": {"$in": ["ai", "database"]}})
~~~

## 3. 逻辑组合

~~~python
collection.get(
    where={
        "$and": [
            {"category": "technology"},
            {"year": {"$gte": 2025}},
        ]
    }
)
~~~

$and 要求全部条件成立，$or 要求至少一个条件成立。一个过滤对象中不要随意并列多个字段，应使用明确的逻辑操作符。

## 4. 数组 Metadata

新版本 Chroma 支持同类型数组 Metadata，并可使用 $contains 和 $not_contains：

~~~python
collection.get(where={"tags": {"$contains": "vector"}})
~~~

数组不能为空，不能嵌套，并且元素类型应一致。

## 5. 文档内容过滤

~~~python
collection.get(
    where_document={"$contains": "Chroma"}
)
~~~

还可以使用 $not_contains、$regex 和 $not_regex。全文过滤通常区分大小写。

## 6. 组合过滤与向量查询

~~~python
collection.query(
    query_embeddings=[[0.1, 0.2, 0.3]],
    n_results=5,
    where={"category": "technology"},
    where_document={"$contains": "Chroma"},
)
~~~

过滤会缩小候选范围。结果为空时，先单独取消 where 和 where_document，判断是向量查询问题还是过滤条件问题。

## 7. ID 与分页

get 支持 ids、limit 和 offset。query 也可以通过 ids 限制允许搜索的记录范围。

~~~python
collection.get(limit=100, offset=0)
collection.get(limit=100, offset=100)
~~~

分页遍历时应指定稳定的处理方式，不要默认一次读取整个集合。

## 8. 本章练习

为记录设计 category、year、tags 三类 Metadata，分别练习等值、范围、集合、数组、$and、$or 和文档内容过滤，然后组合到 query 中。
