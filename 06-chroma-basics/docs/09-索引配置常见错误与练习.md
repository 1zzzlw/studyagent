# 第 9 章：索引配置、常见错误与练习

## 本章目标

理解最常见的向量索引配置，形成不依赖业务项目的 Chroma 排错顺序，并完成一组独立单元练习。

## 1. HNSW

单节点 Chroma 使用 HNSW 近似最近邻索引。它通过图结构在大量向量中快速寻找近邻，速度更快，但结果属于近似搜索。

入门阶段通常不需要调整 HNSW 参数。先正确理解数据、维度、距离和过滤，再做性能调优。

## 2. 距离空间

~~~python
collection = client.create_collection(
    name="cosine_collection",
    configuration={
        "hnsw": {
            "space": "cosine"
        }
    },
)
~~~

| space | 含义 | 常见理解 |
| --- | --- | --- |
| l2 | 平方欧氏距离 | 比较绝对几何距离，默认值 |
| cosine | 余弦距离 | 更关注方向，文本向量常用 |
| ip | 内积距离 | 同时受方向和向量模长影响 |

Chroma 返回的是 distance。以 cosine 为例，它使用 1 - cosine similarity，因此通常越小越接近。

## 3. 常见 HNSW 参数

| 参数 | 影响 |
| --- | --- |
| space | 距离函数 |
| ef_construction | 建索引时的候选范围 |
| ef_search | 查询时的候选范围 |
| max_neighbors | 图中每个节点的最大邻居数 |
| num_threads | 构建和查询线程数 |
| batch_size | 索引批处理大小 |
| sync_threshold | 持久化同步阈值 |

提高搜索范围通常能改善召回，但会增加查询时间或内存消耗。没有评测数据时不要盲目调参。

## 4. 常见错误排查顺序

### 找不到 Collection

检查 Client 类型、持久化 path、host、port、Tenant、Database 和 Collection 名称。

### count 为 0

确认 add/upsert 是否执行成功、是否写入了另一个目录或另一个 Database。

### 向量维度错误

检查第一批写入向量的维度，以及后续 add、update、upsert、query_embeddings 的维度。

### query 返回空结果

先移除 where、where_document 和 ids 限制，再确认 Collection 中有数据。

### get 有数据但 query 不正确

确认使用的是 query 而不是 get，并检查距离空间、查询向量和 n_results。

### 返回字段为 None

检查 include 是否包含需要的 documents、metadatas、distances 或 embeddings。

### 重启后数据消失

确认使用 PersistentClient 或服务端模式，并打印持久化目录绝对路径。

### 第一次运行下载模型

只传 documents 时，默认 Embedding Function 可能需要下载模型。若本章只想练习 Chroma，请手动提供固定维度 embeddings。

## 5. 单元练习清单

不要复制完整答案，每题单独写一个代码单元：

1. 创建 EphemeralClient 并确认重启后数据变化。
2. 创建 PersistentClient 并确认重启后数据保留。
3. 分别使用 create_collection、get_collection 和 get_or_create_collection。
4. 插入三条带不同 Metadata 的记录。
5. 比较 add 和 upsert 处理重复 ID 的结果。
6. 使用 get 按 ID 读取。
7. 使用 get 完成 limit/offset 分页。
8. 使用 query_embeddings 完成单查询和批量查询。
9. 使用 where 完成等值、范围、$in、$and 和 $or 过滤。
10. 使用 where_document 完成包含和正则过滤。
11. 使用 include 控制返回字段。
12. 分别执行 update、upsert 和 delete。
13. 修改 Collection 名称和 Metadata。
14. 启动 Chroma Server 并通过 HttpClient 连接。
15. 制造一次维度不一致异常并写出排查过程。

## 6. 学完标准

→ 插入 Record
→ get / query
→ 条件过滤
→ update / upsert
→ delete
→ 持久化和服务端连接
→ 排查常见错误
~~~
