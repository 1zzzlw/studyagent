# 第 3 章：扫描文档与切块

## 本章目标

理解为什么向量化之前必须先切块，并能通过打印结果判断切块是否合理。

## 1. 文件扫描

教学代码在 `embedding_lab/documents.py` 中递归查找：

```text
storage/knowledge_base/**/*.md
```

路径会排序，保证同一份知识库每次以相同顺序处理。`BLUEPRINT-SPEC-MINIMAL.md` 被排除，因为 WildAgent 会把它作为基础规范直接注入 Prompt，不需要再被普通 RAG 召回。

各级 `README.md` 被标记为：

```python
doc_scope = "index"
```

其他业务文档标记为 `generation`。查询时只检索 `generation`，避免目录说明挤占 Top-K。

文件开头的 YAML frontmatter 会先从正文中移除，避免把 `status`、`authority` 等 metadata 本身当成一块知识向量化。教学版暂不解析这些字段，生产版 WildAgent 会解析并用于过滤和排序。

## 2. 为什么不把整个文件直接向量化

一个 Markdown 可能同时讲门、窗、屋顶和材质。若整篇只有一个向量：

- 多种主题会被压进同一个表示，召回不精确；
- 命中后要把整篇交给聊天模型，浪费上下文；
- 很难指出答案来自哪个标题。

块也不能过小。若一条规则的条件和结论被拆开，召回其中一半仍无法回答。

## 3. 本教程的两阶段切块

`embedding_lab/chunking.py` 先按 Markdown 标题拆章节：

```text
# → ## → ### → #### → #####
```

再只对过长章节使用一个“优先在段落、换行和句末断开”的滑动窗口：

```python
chunk_size = 900
chunk_overlap = 150
```

每个子块都会补上：

```text
> 知识路径：一级标题 > 二级标题 > 当前标题
```

这样文本块脱离原文件后，仍保留语义位置。

## 4. 运行与观察

```powershell
uv run python 07-embedding-basics\run.py inspect --limit 10
```

先肉眼回答四个问题：

1. 一条关键规则是否仍完整？
2. JSON 代码块或 Markdown 表格是否被切得难以理解？
3. 标题路径是否能说明这块在讲什么？
4. 是否出现大量几乎相同的块？

只有切块合理，才值得花费接口调用去生成向量。

## 5. ID 和 metadata 的作用

每个块拥有稳定 ID，计算输入包含：

```text
namespace + 相对文件路径 + 块位置 + content_hash
```

metadata 保存：

- `source`：相对文件路径；
- `heading`：标题路径；
- `doc_scope`：普通生成知识或索引说明；
- `chunk_index` / `part_index`：块位置；
- `content_hash`：正文摘要。

这些字段让后续同步知道哪些块新增、哪些块已失效，也让查询结果可以展示真实来源。

## 6. 与 WildAgent 的差异

教学版使用标准库实现最小切块，保证即使主机暂时无法导入 LangChain，仍能先运行 `inspect` 学习。WildAgent 的 `MarkdownChunker` 使用 `MarkdownHeaderTextSplitter` 和 `RecursiveCharacterTextSplitter`，并且还会：

- 解析 frontmatter 与 `rag-meta`；
- 继承业务实体 metadata；
- 保护表格和代码块等原子内容；
- 生成 parent chunk 信息；
- 处理跨文件正文去重所需的哈希。

这些属于生产知识治理，不影响先理解“标题切块 + 长度兜底”这一主线。

### Cell 3：扫描和读取文档

依赖：Cell 2。

```python
paths = collect_markdown_paths(knowledge_dir)
documents = load_documents(knowledge_dir)

print("扫描路径：", [path.name for path in paths])
assert "BLUEPRINT-SPEC-MINIMAL.md" not in [path.name for path in paths]
assert all("status: approved" not in document.text for document in documents)
assert any(document.doc_scope == "index" for document in documents)
```

### Cell 4：切块并观察 metadata

依赖：Cell 3。

```python
chunker = MarkdownChunker(chunk_size=200, chunk_overlap=20)
chunks = chunker.split_documents(documents, namespace="chunking_test")

for chunk in chunks:
    print("\n---")
    print("id:", chunk.id[:16])
    print("source:", chunk.metadata["source"])
    print("scope:", chunk.metadata["doc_scope"])
    print("heading:", chunk.metadata["heading"])
    print(chunk.text)

assert any("墙体 > 幕墙" in chunk.metadata["heading"] for chunk in chunks)

second_run = chunker.split_documents(documents, namespace="chunking_test")
assert [chunk.id for chunk in chunks] == [chunk.id for chunk in second_run]
```
