## 1. 为什么你会跟丢代码

因为一条用户消息不会直接从 WebSocket 跳到某个建筑节点。中间至少存在四次“形态变化”：

```text
TypeScript 请求对象
→ WebSocket JSON 文本
→ Python dict
→ GenerationJob.payload
→ GenerationState
→ 节点局部输出
→ LangGraph 事件
→ WebSocket 业务事件
→ 前端 Store 状态
```

如果只搜索用户输入的文字，或者只搜索一个节点名称，很容易在这些边界处断掉。

## 2. 六个对象不是一回事

| 对象 | 主标识 | 谁创建 | 是否会比 WebSocket 活得更久 |
|---|---|---|---|
| 连接 | WebSocket 对象 | 浏览器与 FastAPI | 否 |
| 请求 | `request_id` | 前端协议函数 | 可以 |
| 会话 | `session_id` | 会话 Store/服务 | 可以 |
| 后台任务 | `GenerationJob` | `GenerationJobService` | 可以 |
| Graph 执行 | `thread_id` | `_handle_with_langgraph()` | 可以借 Checkpoint 恢复 |
| 事件 | `type`、可选 `event_seq` | Graph 适配层/任务服务 | 持久化事件可以 |

最重要的关系是：

```text
一条连接可以发送多个请求
一个会话可以包含多个请求
一个请求对应一个持久化任务
一个任务驱动一次可恢复的 Graph 执行
一次 Graph 执行经过多个节点并产生多个事件
```

## 3. 本章只跟 chat 最短分支

第一次阅读不要跟完整建筑生成。先假设分类结果是 `chat`：

```text
user_message
→ GenerationJob
→ classifier
→ chat
→ END
→ agent_reply
```

等这条最短链完全清楚，再把 `chat` 换成 `generate`。否则会同时撞上计划审核、平面审核、风格审核、动态节点、校验与修复。

### Cell 3：用最小函数模拟形态变化

- 依赖：Cell 1；
- 是否联网：否；
- 预期：同一个 `request_id` 穿过每一层，但对象类型发生变化。

```python
import json


def frontend_send(payload: dict) -> str:
    return json.dumps(payload, ensure_ascii=False)


def websocket_receive(raw_text: str) -> dict:
    return json.loads(raw_text)


def create_job(data: dict) -> dict:
    return {
        "request_id": data["request_id"],
        "session_id": data["session_id"],
        "status": "running",
        "payload": dict(data),
    }


def create_initial_state(job: dict) -> dict:
    payload = job["payload"]
    return {
        "request_id": job["request_id"],
        "session_id": job["session_id"],
        "user_message": payload["message"],
        "intent": None,
    }


raw_text = frontend_send(request_payload)
server_data = websocket_receive(raw_text)
job = create_job(server_data)
initial_state = create_initial_state(job)

print(type(raw_text).__name__, raw_text[:60])
print(type(server_data).__name__, server_data["request_id"])
print(type(job).__name__, job["status"])
print(type(initial_state).__name__, initial_state)
```

## 5. 常见问题

### WebSocket 断开是否等于 Graph 停止

当前主路径不等于。任务由 `GenerationJobService` 持有，连接只是事件订阅者。是否能恢复还依赖任务状态和 Checkpoint，后续章节再展开。

### 为什么先跟 chat 分支

因为它仍经过 WebSocket、任务服务、Graph 和事件返回，却只包含 `classifier → chat → END`，最适合建立坐标系。
