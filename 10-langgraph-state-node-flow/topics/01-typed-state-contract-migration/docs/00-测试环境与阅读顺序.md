## 为什么不用 WildAgent 测试

本专题训练的是设计方法。直接 import WildAgent 会引入配置、数据库、模型客户端和当前工作区改动，使“契约问题”与“运行环境问题”混在一起。学习实现只复刻结构原则，不复制生产实现。

## 错误实验

从 WildAgent 根目录直接执行 Step 2，观察 tests 路径找不到。回到 studyAgent 根目录再运行。这个错误用于理解测试路径与生产项目完全隔离。
