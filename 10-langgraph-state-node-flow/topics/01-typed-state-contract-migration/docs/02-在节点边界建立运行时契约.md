# 第02章：在节点边界建立运行时契约

## 本章目标

理解“State 继续使用可序列化 dict”和“领域数据使用 Pydantic”为什么可以同时成立，并用测试验证节点只返回自己拥有的局部更新。

源码锚点：[DesignDocument 与节点边界](../contract_pipeline.py)、[RuntimeContractTests 与 NodeBoundaryTests](../tests/test_contract_pipeline.py)。WildAgent 对照：[contracts.py](../../../../../WildAgent/wild-server/app/design/contracts.py)、[architecture_node.py](../../../../../WildAgent/wild-server/app/agent/nodes/architecture_node.py)。

## 1. 推荐的节点边界

```text
checkpoint 中的 dict
→ DesignDocument.model_validate()
→ 类型化领域逻辑
→ model_dump(mode="json")
→ 节点局部 update
→ LangGraph 合入完整 State
```

对应学习实现：

```python
def architecture_node_update(raw_document: dict) -> dict:
    document = DesignDocument.model_validate(raw_document)
    return {
        "design_document": document.model_dump(mode="json"),
        "design_review_status": "pending",
    }
```

类型化模型不一定要直接常驻 checkpoint。关键是在每个领域边界重新校验，并只向 State 返回可序列化数据。

## 2. 为什么不把整个 GenerationState 变成一个大 Pydantic Model

生成、编辑、问答分支需要不同字段；一个巨型模型会产生大量 Optional 字段，仍然无法表达“进入 compiler 节点时哪些字段必须存在”。更合适的分层是：

| 层 | 类型策略 |
| --- | --- |
| Graph 运输 State | 小型 TypedDict、按 channel 分组、允许分支缺省 |
| 节点输入领域对象 | Pydantic model_validate |
| 节点输出 | 明确所有权的局部 dict |
| 持久设计 | 版本化 Pydantic schema 的 JSON |
| 编译产物 | 独立 GenerationSpec schema |

真正的强制点在节点边界，而不是把所有可能字段塞进一个总模型。

## 4. 节点所有权测试

`NodeBoundaryTests` 要求 architecture update 只能返回：

```python
{"design_document", "design_review_status"}
```

随后 `apply_state_update()` 模拟 LangGraph 普通 channel 合并，确认 `request_id` 和 `user_message` 没有丢失。

这个规则带来两个好处：

- 节点不能复制并覆盖自己不拥有的旧字段；
- 测试能从返回 key 直接审计节点职责。

## 单元测试练习

### Step 1：运行契约测试

- 输入：`-k RuntimeContractTests`；
- 预期：3项通过；
- 观察：异常发生在 model_validate，而不是 compiler。

### Step 2：运行节点边界测试

- 输入：`-k NodeBoundaryTests`；
- 预期：2项通过；
- 观察：局部 update 与合并后的完整 State 形状不同。

### Step 3：主动破坏节点所有权

暂时让 `architecture_node_update()` 多返回 `request_id="wrong"`。运行 NodeBoundaryTests，观察精确 key 集合测试失败。然后恢复实现。

### Step 4：增加一个跨字段错误

在 `sample_document()` 中把 upper_pattern 的一个 window 改成 door。预测应由哪个 validator 拒绝，再运行 RuntimeContractTests 对照。

## 错误实验

删除 `model_dump(mode="json")`，让节点把 Pydantic 对象直接写入 update。对象在内存中可能可用，但 JSON checkpoint、WebSocket 或持久化边界可能失败。State 数据应显式转换为协议形式。
