# 公共契约

这里只规划各系统都能理解的基础数据。具体业务类型仍归各自系统。

| 规划文件 | 数据 |
| --- | --- |
| `messages.py` | `Message`：消息 ID、会话 ID、发送角色、发送者标识、正文、带时区时间 |
| `observations.py` | `Observation`：观察 ID、角色 ID、来源消息 ID、本次实际获知内容及时间 |
| `clock.py` | 统一获取当前时间的薄入口，便于后续进行显式时间推进 |

## 原始消息与观察

消息记录“谁实际说了什么”。观察记录“角色实际获知了什么”。

同一观察可以形成多条记忆；它们共同引用观察编号和真实来源消息。不要让模型自行生成可追溯的消息 ID。

第一版主要接收文字对话；以后显式环境事件也可以产生观察，但本轮不实现随机事件系统。

## 人物身份的最小区分

- `character_id`：记忆、状态和情绪属于哪个角色。
- `conversation_id`：原始交流属于哪个会话。
- `speaker_id / role`：谁说了这句话。

用户说“我累了”记录的是用户的陈述，不能直接据此把角色自己的 `energy` 调低。

不在公共层放全局可变 `PersonState`，也不把所有系统的计算集中到公共工具文件。
